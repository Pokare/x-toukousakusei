# Gemini 3.8 Flash TTS × Claude Opus 5.5 で作る解説動画

KEITO さん（[@keitowebai](https://x.com/keitowebai)）が 2026-09-25 に投稿した
「Gemini 3.8 Flash TTS × Opus 5.5で動画作るの熱そう！」の動画（1分40秒・1920×1080）を、
**同じ作り方で再現し、少し磨き上げた** Remotion プロジェクトです。

- **ナレーション**: Gemini 3.8 Flash TTS（台本の行ごとに演技指示をつけて生成）
- **映像**: Claude Code（Opus 5.5）が React / Remotion のコードでモーショングラフィックスを描画
- **字幕・演出のタイミング**: 生成した音声の長さから自動計算（声を差し替えても自動で合い直す）

```
台本(JSON) ──▶ Gemini 3.8 Flash TTS ──▶ 行ごとのWAV ＋ 長さ ＋ 音量データ
                                              │
Claude Code(Opus 5.5) が書いた Remotion シーン ◀┘ ──▶ MP4（1920×1080 / 30fps）
```

各要素の位置とサイズは元動画のフレームから実測して合わせています。

## ブラッシュアップした点

1. **音声と映像の自動同期** — すべての演出を「どの行の何秒目か」で指定しているので、声・台本を変えても `npm run tts` だけで全体のタイミングが合い直します。
2. **波形が本物の声に反応** — 生成した音声の音量・帯域をフレームごとに解析し（`public/voice/levels.json`）、波形アニメに使っています。演技パートの波形は、ささやき・笑い・ため息の実際の声の形がそのまま記録されます。
3. **控えめな効果音** — カードの出現、タイプ音、ボタン、1位のチャイムなど。音はスクリプトで合成しているので権利の心配がありません（`--props '{"sfx":false}'` で無効化）。
4. **無料枠で回るTTSパイプライン** — 35行を「同じ声・同じ演技指示」ごとにまとめ、**Gemini の呼び出し9回**で全ナレーションを生成します（無料枠は1日のリクエスト数が少ないため）。生成結果は行ごとにキャッシュされ、直した行だけ作り直せます。
5. **APIキーなしでも全体を確認できる仮音声**（Open JTalk）。

## 必要なもの・費用

| もの | 用途 | 費用 |
|---|---|---|
| Claude Pro / Max | Claude Code（Opus 5.5）で映像のコードを書く・直す | サブスク内 |
| Gemini API キー | Gemini 3.8 Flash TTS でナレーション生成 | [Google AI Studio](https://aistudio.google.com/apikey) で無料発行。無料枠内で生成可（有料枠でも100秒で数円程度） |
| Node.js 20 以上 | Remotion で描画・書き出し | 無料 |
| Python 3 ＋ `pyopenjtalk-plus`（任意） | APIキーなしで試す仮音声 | 無料 |

※ 無料枠の上限（1日あたりのリクエスト数など）は変わることがあります。上限に当たったら翌日に続きから実行すれば、キャッシュ済みの行はスキップされます。

## 使い方

```bash
npm install

# 1) APIキーを設定（どちらか）
#    ・環境変数 GEMINI_API_KEY に設定（Claude Code on the web なら環境設定の環境変数に追加して新しいセッションを開始）
#    ・プロジェクト直下に .env.local を作って  GEMINI_API_KEY=xxxx  と書く（.gitignore 済み）
#    キーはチャットやコードに貼らないでください。

# 2) ナレーションを生成（Gemini 3.8 Flash TTS / 9回の呼び出し）
npm run tts
#    まず計画だけ見る:        npm run tts -- --dry-run
#    特定の行だけ作り直す:    npm run tts -- --only s2-3,s2-4 --per-line
#    キーなしで仮音声:        npm run tts:placeholder   （要: pip install pyopenjtalk-plus numpy）

# 3) プレビュー（ブラウザで確認・微調整）
npm run dev

# 4) 書き出し
npm run render     # → out/video.mp4（H.264 / AAC 192kbps / 1920×1080 / 30fps）
npm run still      # → out/thumbnail.png（投稿のサムネイル候補）
```

## 台本・声を変えるには

- **台本**: `narration/script.json` の `text`（字幕兼読み上げ）を編集。読み方を変えたいときは `speak`（Gemini 用）や `yomi`（仮音声用）を追加。
- **声と演技指示**: `narration/voices.json`
  - `gemini.voice` … 既成ボイス名（Aoede, Kore, Gacrux, Leda, Puck など）、または AI Studio の Voice Design / クローンで作ったカスタムボイスID（`voice_...`）
  - `gemini.style` … 演技指示（例:「ささやき声で。耳元で秘密を打ち明けるように…」）。読み上げられません。
  - `gainDb` … 仕上がりの音量（ささやきを小さく等）
- 変更後は `npm run tts` → `npm run render`。映像のタイミングは自動で追従します。
- 行の間・セクション間の間合いは `script.json` の `timing`（`lineGap` / `sectionGap`）で調整。

## Claude Code に頼むときのコツ（この動画の作り方）

1. 元にしたい動画のフレームを Claude Code に見せ、**色・サイズ・配置を実測**させる（このプロジェクトでは 2fps で全フレームを書き出して比較）。
2. 台本を JSON にし、**演出は必ず「行の開始/終了」基準で書かせる**（秒数を直書きさせない）。
3. シーンごとに「元動画と同じ位置の静止画を左右に並べて比較 → 直す」を繰り返させる。
4. 最後に全体を書き出して通しで確認。

## ファイル構成

```
narration/script.json     台本（35行・7パート）と間合い
narration/voices.json     声・演技指示の設定
scripts/tts.mjs           ナレーション生成（Gemini / 仮音声）→ public/voice/
scripts/providers/        Gemini 3.8 Flash TTS 呼び出し・仮音声
scripts/lib/wav.mjs       WAV処理（行の切り分け、音量正規化、波形用の解析）
scripts/make-sfx.mjs      効果音の合成
src/timeline.ts           音声の長さから全行・全パートの時刻を計算
src/scenes/*.tsx          各パートの映像（Claude Code が作成）
src/components/           字幕、波形、カード、アイコンなど共通部品
src/dev/*.tsx             シーン単体のプレビュー用エントリ
public/voice/             生成済みナレーション（現在は仮音声）
```
